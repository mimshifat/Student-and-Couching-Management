feat: complete offline-first firestore sync architecture

This commit implements the full end-to-end sync feature for the coaching app:

1. Offline-First SQLite Foundation:
   - Added sync_map, sync_outbox, and sync_meta tables.
   - Implemented SQLite triggers for real-time offline change tracking.

2. Firebase Authentication & Security:
   - Added Email/Password and Google Sign-in via AuthGate.
   - Integrated Firebase App Check (Play Integrity) for Android.
   - Deployed strict Firestore Security Rules based on UID.

3. Background Sync & Restore Engine:
   - Configured WorkManager for background syncing outbox.
   - Built SyncMapper and SyncRestore to handle complex schema mapping and foreign key dependencies.
   - Upgraded backup repository to safely migrate local DB ownership.

4. Multi-Device Locking & Admin Controls:
   - Implemented SessionManager for single-device active editing.
   - Added 'status' field management for immediate user suspension/deactivation via Firebase Console.

5. Production Readiness:
   - Fixed all linter analysis warnings.
   - Added ProGuard rules and enabled R8 shrinking for release builds.
